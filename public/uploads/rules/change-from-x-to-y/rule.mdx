When requesting small content changes, use "change from X to Y" to show the current content and your proposed replacement. This applies to web pages, documents, slides, video captions, and other content.

This process consists of including the original version of the content ("X") along with the changes you require ("Y"). It means you easily see the page or file content as it was prior to your changes.

This history is convenient for **future reference** and also **makes it very clear** to the person doing the changes exactly what the new file is meant to look like.

<endIntro />

Use this format wherever you give feedback, including email, chat, review comments, and discussion pages. Include a link and the exact location, such as a heading, slide number, or video timestamp.

This format helps communicate individual edits. For larger changes, use your team's content management and approval workflow.

## Using email to request small edits

Make the changes even easier to see and understand by highlighting:

* In <mark style={{ backgroundColor: "#FEF08A" }}>yellow</mark> - Content you want to add/update (only do this on the "To" section)
* In <mark style={{ backgroundColor: "#CC4141" }}>red</mark> (with white and bold text) - Content you want to delete, whether it be specific text or an entire sentence (only do this on the "From" section)
  **Note:** Only indicate in red the content that will **not** be replaced/updated with something correlated.

<boxEmbed
  body={<>
    **Note:** All text we do **not** write ourselves [should be indented](/do-you-use-indentation-for-readability), so this includes paragraphs you are copying and pasting.
  </>}
  figurePrefix="none"
  figure=""
  style="warning"
/>

## Using feedback to improve video captions

A lower third is text near the bottom of a video, such as a speaker's name or job title. Include a screenshot and timestamp so the editor can find the text you want to change.

<imageEmbed alt="Video lower third showing Andreas Lengkeek and the title SSW Senior Software Architect" size="large" showBorder={true} figurePrefix="none" figure="A screenshot identifies the lower third you want the editor to change" src="/uploads/rules/change-from-x-to-y/video-lower-third.png" />

<boxEmbed
  style="greybox"
  body={<>
    **Example request:** In the linked draft video at 00:05, please shorten the lower-third job title:

    **From:** SSW Senior Software Architect

    **To:** Senior Software Architect

    **Reason:** The SSW logo already identifies the company.
  </>}

## Wikipedia - Use Talk pages to suggest changes

If you are unsure about an edit to a Wikipedia article, suggest it on the article's **Talk** page. Check for an existing discussion before starting a new topic. Use "from X to Y" to make your proposal easy to compare, and explain why it improves the article. Include reliable sources when proposing factual changes.

<imageEmbed alt="Wikipedia's Talk:Australia page with the Talk tab selected and Add topic visible" size="large" showBorder={true} figurePrefix="none" figure="Feedback on a Wikipedia Talk page is easier to digest when you use change from X to Y" src="/uploads/rules/change-from-x-to-y/wikipedia-talk-page.png" />

Screenshot: [Talk:Australia](https://en.wikipedia.org/wiki/Talk:Australia), by Wikipedia contributors, available under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

<boxEmbed
  style="greybox"
  body={<>
    **Illustrative Talk page proposal:** In the History section, please change:

    **From:** The museum was opened in 1990.

    **To:** The museum opened in 1990.

    **Reason:** Shorter wording with the same meaning.
  </>}
  figurePrefix="good"
  figure="A proposed wording change is specific and easy for other editors to discuss"
/>

See [Wikipedia's Talk page guidelines](https://en.wikipedia.org/wiki/Wikipedia:Talk_page_guidelines) for discussion etiquette. A clear proposal helps discussion but does not guarantee agreement.

## Using AI to suggest changes

Don’t tell AI to rewrite your email. Instead use change x to y format too.

Prompt example:

<boxEmbed
  body={<>
    Check the below email. Number your suggestions in the form of change x to y eg.

    \[number] change \[new line]

    x \[new line]\
    to \[new line]\
    y \[new line]
  </>}
  figurePrefix="good"
  figure="Training AI to use &#x22;from X to Y&#x22;"

## Alternative - What if there are too many changes?

Sometimes you have a lot of content and too many changes, making the process "from X to Y" too arduous. In this case is recommended to use [Word 'Track Changes'](https://support.microsoft.com/en-gb/office/track-changes-in-word-197ba630-0f5f-4a8e-9a77-3712475e806a?ui=en-us\&rs=en-gb\&ad=gb) functionality.

## Alternative - What if you have a website managed by GitHub?

Some websites use GitHub to manage their files (e.g. [SSW Rules](https://github.com/SSWConsulting/SSW.Rules.Content)). GitHub makes reviewing changes easy through "Pull Requests".
