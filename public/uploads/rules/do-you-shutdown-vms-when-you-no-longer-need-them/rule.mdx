Often we use Azure VM's for presentations, training and development. As there is a cost involved to store and use the VM it is important to ensure that the VM is shutdown when it is no longer required.

<endIntro />

Shutting down the VM will prevent compute charges from incurring. There is still a cost involved for the storage of the VHD files but these charges are a lot less than the compute charges.

Please note that is for [Visual Studio subscriptions](https://azure.microsoft.com/en-us/services/developer-tools/visual-studio-subscriptions/?WT.mc_id=AZ-MVP-33518).

Deallocate the VM so its status reads **Stopped (deallocated)**, for example with `az vm deallocate`. Shutting down from inside the VM leaves it **Stopped**, and Azure [still bills the compute](https://learn.microsoft.com/en-us/azure/virtual-machines/states-billing). Set [auto-shutdown](https://learn.microsoft.com/en-us/azure/virtual-machines/auto-shutdown-vm) so dev VMs stop on their own after hours.

## Idle dev and test resources still cost money

Dev and test environments are used during work hours and billed around the clock. Each service stops costing money in a different way:

| Resource | How to stop paying while it is idle |
| --- | --- |
| App Service | Scale the plan down to the Free tier, or delete it. The plan is charged even with no apps in it |
| Container Apps | Set the minimum replicas to 0. At zero replicas there are no usage charges |
| Azure SQL Database | Use the serverless tier with auto-pause. While it is paused, only storage is billed |
| Azure AI Search | It cannot be paused. On the Dedicated model you must delete the service to stop the bill |
| AI model deployments | Pay-per-token deployments are only charged when called. Provisioned and fine-tuned deployments are billed by the hour whether they are used or not, so delete them |
