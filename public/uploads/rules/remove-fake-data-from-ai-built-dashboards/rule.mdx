A support lead changes the date range on a new AI-built dashboard, but nothing moves. Placeholder escalations appear beside operational records, and the health badge never changes. The page looks finished before its data and controls work.

**Remove sample data and dead controls before sharing an AI-built dashboard.** Check what the page does, not just how it looks.

## Keep samples out of live mode

Sample data helps the assistant draw a page before a source connects. Keep it in a separate, visibly labelled demo mode with a separate data path. Never fall back to sample rows when a live request fails: readers could act on invented results.

If a panel cannot be computed, leave it empty and explain why. Northwind's returns panel says the inbox is not connected. A successful empty query can show zero; an unavailable source cannot. See [showing missing and stale data](/show-missing-and-stale-data-on-dashboards).

## Wire every control or remove it

A selected filter promises that the displayed results reflect that selection. A button promises an action. [Native button semantics](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button) support interaction; drawing something that looks clickable does not implement it.

Northwind removes the dead Auto-resolve buttons and keeps Feature and Dates dropdowns wired to the queries. If a capability is deliberately unavailable, label why it is disabled. Don't leave an enabled control that silently does nothing.

## Make the mode and build visible

Label the page **Live** or **Demo**, and show its actual build time. Compute health badges from the build results. Northwind's fixture reports 2,371 of 2,412 emails parsed (98.3%) and sample mode off; it does not type a reassuring percentage into the layout.

## Try the page before sharing it

Choose two date ranges with different known records. Check every affected tile, chart and list against those records; then test Feature in combination with Dates. An unaffected panel should explain its separate scope.

Activate each control with a mouse and keyboard and confirm its intended result. Disconnect a source and verify that its panel explains the gap without inserting samples. Finally, open live mode with the demo source unavailable: it should still work from its approved source.

[Traceable dashboard calculations](/ai-dashboards-with-insights) provide the data; [independent reconciliation](/check-dashboard-totals-against-the-source) checks that the connected totals are right.
