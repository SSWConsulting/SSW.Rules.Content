A tile turns red because support chat accuracy "fell" from 86% to 77%, and the AI insight blames the release beside the dip. A "Top 5" ranks five questions at 100% from 6 checks each. Small weekly samples move a lot by chance, but the dashboard presents a verdict.

That's why you should **show the evidence behind every percentage and colour a change only when a test shows it is clear**.

## Show the count beside every percentage

Show **47/61 · 77%**, not just 77%. Call the measure "answers a support agent agreed with" so readers know what passes a check. Optionally add a 90% range using the [Wilson method](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm).

## Colour the change, not the level

"Red under 80%" fires on noise. Colour only when a planned [two-proportion test](https://www.itl.nist.gov/div898/handbook/prc/section3/prc33.htm) against the previous period gives p below 0.05:

* **No clear change yet** - Support chat at 47/61 against 55/64 gives p = 0.20
* **Clear rise** - Descriptions at 44/52 against 30/50 give p = 0.005

Put the plain phrase on the tile and the p-value in the drill-in. "No clear change yet" means these checks can't separate the move from chance, not that nothing changed.

The 0.05 threshold holds for one planned comparison. Across many tiles and repeated looks, some cross it by chance, so set the comparisons before you look, use a method that controls false alerts across them, and check that the change is big enough to matter.

Weekly comparisons catch only big moves. Spotting a fall from 86% to 71% reliably (80% power, 5% test) takes about 117 checks per period, so at about 60 checks a week, compare 2-week periods.

## Check where the checks came from

One review session on 9 Oct supplied 17 of the 61 checks (28%). Without it, the result is 33/44 (75%), so the dip doesn't hinge on that batch. Ranges and tests like these assume independent checks. When several checks share a conversation or a review session, the result looks more certain than it is. No range fixes bias either: if reviewers only pick complaints, the rate describes complaints.

## Make leaderboards earn their rankings

Require at least 10 checks before ranking. Rank the best by the low end of the range and the worst by the high end, so a perfect score from few checks can't top the list. Northwind's 58/60 (90–99%) ranks above 19/19 (88–100%). "Do you ship to Brazil?" at 6/6 shows "Not ranked yet", with a range of 69–100%.

## Mark changes that can move the result

Mark prompt, model and data changes, not every release. Northwind marks only the 7 Oct description prompt change. A marker shows timing, not cause. Test changes before release: [Do you run evals on your AI features?](/run-evals-on-ai-features).
