Bold tags like `<b>` or `<strong>` inside a heading mix styling into your content. When some headings have them and others don't, the headings on a page stop looking the same. The same goes for `**` in Markdown headings.

Keep headings as plain text, and style them in CSS.

If you need bold headings, make them bold in your CSS:

```css
h1 {
  font-weight: bold;
}
```
