Your team spends months coding a chatbot from scratch: hosting it, making it search your documents, and checking who's allowed to see what. Microsoft's no-code and low-code tools give you all of that out of the box.

**Pick the simplest tool that does the job, and only write code when something forces you to.**

<endIntro />

## What are your options?

| Tier | Tool | What it is |
| --- | --- | --- |
| Ready-made | Copilot in SharePoint, Word, Excel, and PowerPoint, and ready-made agents in Copilot | Already there with a Microsoft 365 Copilot licence. Try it before you build anything |
| No-code | Agent Builder | Describe an agent in plain English inside Copilot. Not available in Teams chats |
| Low-code | Copilot Studio | Agents with knowledge, actions, and workflows, for Teams, websites, and more |
| Pro-code | Work IQ Dev Tools (or Agents Toolkit) | Add skills or tools to Microsoft Copilot from code |
| Pro-code | Microsoft 365 Agents SDK | Bot Framework's successor. Connects an app you built to a Copilot Studio or Foundry agent |
| Pro-code | Microsoft Foundry | Build on Azure with your own models, hosting, and networking |

## How do you choose?

## When do you need Copilot Studio?

When the agent needs more than answers in Copilot: taking actions like looking up live data or booking a room, Teams chats or a website, or a way to test changes before they go live.

You still don't write the hard parts: [searching your documents](https://learn.microsoft.com/en-us/microsoft-copilot-studio/knowledge-copilot-studio), signing people in, and publishing to [Teams or a website](https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-fundamentals-publish-channels) come built in.

SSW's SophieBot is a real example. The first version was hand-coded in C#. SSW rebuilt it in Copilot Studio, and it now answers staff questions in Teams from the SSW website, SSW Rules, SharePoint, and CRM, and looks up live data like who is in the office.

## What if you are not a Microsoft shop?

Pick the platform where your documents and user accounts already live.

| Your content mostly lives in | Look at |
| --- | --- |
| Microsoft 365, SharePoint, Dataverse | The tree above |
| Google Workspace or Google Cloud | Gemini Enterprise Agent Platform |
| AWS | Amazon Bedrock AgentCore |
| Salesforce | Agentforce |
| Nowhere in particular | A code-first SDK such as the OpenAI Agents SDK or LangGraph |
