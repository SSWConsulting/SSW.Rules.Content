When someone asks you to read a rule, reading it without any response leaves them guessing. A comment on the rule shows that you have read it and lets you share useful experience with other readers.

<endIntro />

## What should you do?

1. Read the whole rule, including its examples.
2. Give the rule a thumbs up 👍 if you agree with it.
3. If something needs changing, get approval for the change.
4. Once approved, edit the rule.
5. Add a comment with your takeaway, experience, or an additional insight.

The 👍 does not show who gave it, so it cannot confirm that you have read the rule. However, it is a useful mental check: “Do I agree with this, or should something change?” Only give it a thumbs up if you agree.

Your comment is linked to you, so it provides a visible acknowledgement that you have read the rule. Use comments to expand the discussion with practical examples, experiences, or situations other readers might find useful.

If you spot a problem, take responsibility for getting it approved and fixed. Avoid leaving a correction in the comments for someone else to action.
