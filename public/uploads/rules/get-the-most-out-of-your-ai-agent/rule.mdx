An AI agent finishes one task, then waits. You repeat your preferences, chase progress, and still have to check what it delivered. Clear goals and standing orders help it do more useful work with less repeated prompting.

<endIntro />

Use these tips with the tools your agent supports. Give it clear permission before it shares data or takes action in another service.

## Delegate useful work

* **Just ask.** Ask for what you need, even if you have not seen the agent do it before. For example, ask it to turn meeting notes into an action list, then check what access it needs. You may find it can help with more than code.
* **Coordinate from one main agent.** Where supported and authorised, use your main agent to assign work to tools on your other AI subscriptions. For example, it could drive Claude Code through an approved integration.
* **Run independent tasks in parallel.** Ask the agent to check links while another task reviews wording. Keep shared file edits separate, then review the combined result; see [when cloud agents help](/cloud-ai-agents).
* **Keep moving when blocked.** Ask the agent to explain the blocker and continue other useful, authorised work. For example, it can prepare test cases while a design decision is pending.
* **Follow up on pending decisions.** Ask the agent to keep a list of unresolved decisions and remind you when an answer is needed. Set a follow-up time where reminders are supported; see [how to clarify with agents](/ai-efficient-clarify-questions).
* **Ask for a recommendation.** Have the agent give the pros, cons, and its recommended option when it presents a choice. See [how to compare options](/pros-and-cons-and-ratings).

## Set standing orders

* **Save repeated instructions.** Put recurring preferences in the agent's supported instructions or settings. See [global instructions for AI agents](/global-rules-for-ai-agents).
* **Ask for an initial ETA.** Ask for an estimated completion time when you assign a task. Include the assumptions that could change it.
* **Ask for progress updates.** Where ongoing updates are supported, ask for an updated ETA every five minutes while the agent works. Each update should state progress, blockers, and time remaining.
* **Set quiet hours.** For example, request no routine updates from 23:00 to 07:00 in your time zone. Agree how urgent blockers should be handled.
* **Request a daily operations brief.** Ask for one page covering completed tasks, blockers, owners, and next steps. Use supported scheduling for delivery, or request it when you start your day.
* **Use voice for briefings.** Where voice calls are supported, ask for a hands-free briefing, such as on your commute. Start the call safely before driving and keep your attention on the road.

## Get value from your subscriptions

* **Make allowances visible.** Connect your AI plans to the main agent where supported integrations expose allowances and reset times. Otherwise, check the provider dashboard and supply current figures; see [monitoring AI cost and usage](/monitor-ai-cost-and-usage).
* **Plan around resets.** Ask the agent to compare the remaining allowance with the time to reset and suggest useful, approved backlog work before it expires. Include the figures and suggestions in the daily brief; see [displaying usage limits](/customize-your-coding-agent).
* **Build reusable workflows.** Give the main agent goals and use [reusable skills](/ai-agents-with-skills) for recurring work, such as preparing a weekly report. [Share workflows from one source](/centralize-ai-workflows) so improvements apply to future runs.

## Verify completion

* **Ask for evidence.** Require test results and links to completed work, such as a PR. For changes, ask for before and after screenshots and a short video explaining the problem, change, and checks; see [AI-created Done videos](/done-video-by-ai). You can also use ElevenLabs to generate [music](https://elevenlabs.io/docs/overview/capabilities/music) and [sound effects](https://elevenlabs.io/docs/overview/capabilities/sound-effects) for videos.
