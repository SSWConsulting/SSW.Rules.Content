An AI assistant builds Northwind Traders' spend dashboard and writes its query. September's total looks safely under budget, and the AI insight recommends a cheaper model for product descriptions. But the dashboard shows $6,907.40 against a bill of $6,335.71, and support chat actually costs the most. The plausible-looking page points the team at the wrong feature.

That's why you should **check dashboard totals against an independent source before acting on the insights**.

## Compare the same closed window

Use a closed month so the dashboard and its comparison cover a period that no longer changes. Northwind compares September's billed total with the provider invoice, not another tile using the same query. Reusing the calculation can reproduce the error and call it a match.

Check the subtotals as well as the total. Moving cost from one feature to another leaves the total right and the ranking wrong, so Northwind also matches each feature against the provider's cost report by tag.

[Do you use AI to generate useful dashboards with insights?](/ai-dashboards-with-insights) covers wiring each tile to a trusted source. This rule checks those totals against a separate calculation or report.

## Read every row and count each cost once

The assistant assumes 5 features × 30 days and writes `SELECT TOP 150`, ordered by day. But the table holds 180 rows because daily product-description roll-ups repeat the cost of their children. The query drops the last 5 days and counts descriptions twice. The errors partly cancel, leaving the total 9.0% above the bill.

When adding individual costs, exclude summary rows that already include those costs. Exports and APIs return long results in pages, so read every page and compare rows read with rows available: Northwind's export has 11,482 rows across 3 pages, and the dashboard reads them all. Report any query that reaches its row limit, even when its total looks reasonable.

## Keep the comparison on the dashboard

Repeat the comparison on every refresh. Show each dashboard value beside the independent source value in a small table, and flag mismatches before generating advice. Northwind also checks 2,804 resolved chats against the helpdesk report and 9,388 routed emails against the inbox log. Those counts are the denominators for cost per outcome, so they need checking too. See [Do you track AI cost by total and by unit?](/track-ai-cost-by-total-and-unit).

Keep the $5,964.22 token estimate separate from billed spend. It estimates the same activity, so adding it would count costs again. The billed-to-estimated ratio of 1.06× is a comparison, not another charge.
