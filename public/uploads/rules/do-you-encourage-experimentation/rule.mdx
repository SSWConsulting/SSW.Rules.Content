Users are more willing to experiment when they can see the result before committing. Provide a live preview where possible, especially for visual, layout, or configuration changes.

A preview makes experimentation faster and safer by reducing uncertainty and helping users catch mistakes before saving or publishing.

<endIntro />

It should be easy for the user to:

* Undo
* Remember the last state
* **Live preview**
