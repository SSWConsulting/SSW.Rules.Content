At 3 pm, Northwind Traders' support lead opens a dashboard showing 0 chats today and $0 of AI spend. It calls this a "Quiet day" and says spending is "On track". But the chat cache stopped syncing yesterday and the billing export failed, so neither figure is known. The page still says "Updated: just now", though it hasn't rebuilt since 08:10, and its AI insight repeats the false reassurance.

That's why you should **show missing data as unknown and make stale data visible**.

## Keep unknown separate from zero

Only show zero when a successful query confirms it. If the request fails, label the current figure "Cost unavailable" or show a dash. Put the last good value underneath with its coverage date.

Northwind's last good spend is $3,374 to 13 Oct against a $9,000 budget. That can't tell anyone today's budget position, so the tile says "Pace unknown". AI commentary must respect that gap too.

A feed paused for weeks gets the same treatment: a one-line note, not a tile stuck on 0.

For charts, hatch unsynced hours instead of drawing them as zero. Include a partially synced hour in the unknown region, because an incomplete count can still suggest a fall.

## Separate data coverage from pull time

"Pulled 15 Oct 08:10" says when a request runs, not how current its records are. Northwind's chat tile counts whole hours to 14 Oct 18:00, from a cache last synced at 18:02. A fresh pull of an old cache does not make today's chats known.

Track data coverage and the last successful pull time for each metric. If one source fails, keep its last successful pull time even when other sources update. Label different runs "Mixed pulls" and explain any harmless difference: Northwind's 02:00 product-description pull still covers the whole previous day.

## Check age when the page opens

Store the build timestamp and compare it with the browser's clock when the page opens. A "just now" string written during the build cannot reveal a stopped scheduler.

Northwind rebuilds hourly and warns after 2 hours. At 15:10, the 08:10 build shows "Stale: last built 7 h ago" and asks the reader to check the scheduler.
