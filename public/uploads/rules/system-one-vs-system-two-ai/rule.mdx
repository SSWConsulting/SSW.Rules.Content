Everyone wants to integrate AI into their application and workflows, but often times you're using the wrong tool for the task. Most AI work in your app isn't writing, it's deciding. 

System 1 models are built for that, you ask typed questions and you get typed answers with probabilities in blazing fast times. Save generative system 2 models like Claude and ChatGPT for jobs that need reasoning or words. 

<endIntro />

## What are System 1 and System 2 AI?

The term comes from Daniel Kahneman's “*Thinking, Fast and Slow”,* which splits human thinking into two modes. AI models are now splitting the same way.

* **System 1** - is fast and unconscious, it runs constantly without you noticing. Assessing faces, patterns, senses and impressions. It costs no effort. 
* **System 2** - is slow, deliberate an analytical. The thinking deployed for reasoning, writing and planning

Chat interfaces trained us to treat every AI job as System 2. 

## How do they compare?

|          | System 1                                                                              | System 2                                                      |
| -------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Input    | A state (data) and a question (choice, score, or noul)                                | Text, images, files, audio                                    |
| Output   | Structured JSON data containing typed decisions, probabilities, and confidence scores | Free-form text or code                                        |
| Speed    | Ultra-fast - \<1ms                                                                    | Seconds to minutes                                            |
| Cost     | Pay for only input tokens                                                             | Pay for both reasoning tokens and final visible output tokens |
| Best for | Classify, route, score, gate                                                          | Write, summarise, reason, plan                                |
