Everyone wants to integrate AI into their application and workflows, but often times you're using the wrong tool for the task. Most AI work in your app isn't writing, it's deciding.

System 1 models are built for that, you ask typed questions and you get typed answers with probabilities in blazing fast times. Save generative system 2 models like Claude and ChatGPT for jobs that need reasoning or words.

<endIntro />

## What are System 1 and System 2 AI?

The term comes from Daniel Kahneman's “*Thinking, Fast and Slow”,* which splits human thinking into two modes. AI models are now splitting the same way.

* **System 1** - is fast and unconscious, it runs constantly without you noticing. Assessing faces, patterns, senses and impressions. It costs no effort.
* **System 2** - is slow, deliberate and analytical. The thinking deployed for reasoning, writing and planning

Recent chat interfaces trained us to treat every AI job as System 2.

## How do they compare?

|          | System 1                                                    | System 2                           |
| -------- | ----------------------------------------------------------- | ---------------------------------- |
| Input    | Data plus typed questions (yes/no, choice or score)         | Text, images, files, audio         |
| Output   | Selected decisions with probabilities and confidence scores | Free-form text or code             |
| Speed    | Fast - about 100ms                                          | Seconds to minutes                 |
| Cost     | Input tokens only                                           | Input, reasoning and output tokens |
| Best for | Classify, route, score, gate                                | Write, summarise, reason, plan     |

## When should you use System 1?

Reach for it when the answer fits in a dropdown.

* **Triage** - Is this email urgent? Which queue does this ticket belong in? Which branch of your workflow should this run down?
* **Routing** - Does this question need the cheap model, the expensive one, or just a database lookup?
* **Gating** - Does this shell command need a human to approve it before your AI Agent runs it?
* **Scoring** - How well does this CV match the rubric, from 1 to 5?

## When should you use System 2?

Use it when the output is words or code, or when the model has to work out its own next step towards a goal.

* **Writing** - Email replies, summaries, docs
* **Reasoning** - Planning, debugging, and agentic work where the model decides what to do next
* **Extracting exact values** - System 1 models can't reliably pull out dates, amounts or counts
* **Explaining a decision** - System 1 gives you a probability, not a reason

## How do you use both together?

Decide first, generate second. System 1 reads the input, your code branches on the answer, and only the cases that need words reach the LLM.

For example, take a website enquiry form. [Jev](https://typesafe.ai) answers three questions in a single call: Is this spam? Sales or support? Which state? Spam is dropped for a fraction of a cent. Everything else goes to Claude, which drafts a reply for the right person.

Jev launched in September 2026, so pilot it on a low-risk pipeline before you put it anywhere critical.
