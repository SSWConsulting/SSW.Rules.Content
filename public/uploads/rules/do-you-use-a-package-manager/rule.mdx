A package manager is a collection of software tools that automate the process of installing, upgrading, configuring, and uninstalling computer programs in a consistent manner.

<endIntro />

## Windows: winget (Recommended)

[winget](https://learn.microsoft.com/en-us/windows/package-manager/winget/) is Microsoft's own package manager. It ships with Windows 11 and current versions of Windows 10 as part of App Installer, so there is nothing extra to install and it runs inside the operating system's trust model.

Search for a tool with:

```bash
winget search powertoys
```

And then install it with:

```bash
winget install Microsoft.PowerToys
```

winget also suits managed environments. Administrators can use Group Policy and Intune to control whether winget is enabled and which sources users can install from.

For more information, see [Use WinGet to install and manage applications](https://learn.microsoft.com/en-us/windows/package-manager/winget/).

### Chocolatey (Not recommended)

Chocolatey was the best Windows option before winget existed, but installing it now means working against Windows security. The official install opens an elevated PowerShell session, bypasses the execution policy, and runs a script downloaded from the internet:

<boxEmbed
  style="greybox"
  body={<>
    ```powershell
    Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
    ```
  </>}
  figurePrefix="bad"
  figure="Installing Chocolatey bypasses the execution policy and runs a remote script"
/>

Once installed, nothing in Windows itself limits what users install through it, so administrators lose the control that Group Policy and Intune give them over winget.

## macOS: Homebrew

[Homebrew](https://brew.sh/) is the preferred option when on a Mac. Head to their website for installation instructions: [https://brew.sh/](https://brew.sh/)
