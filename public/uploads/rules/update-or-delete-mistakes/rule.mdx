If you notice a mistake in a message you sent in IM (e.g. Microsoft Teams), fix it. How you fix it depends on whether anyone might have already read it or acted on it.

<endIntro />

## Typos and messages sent in error - Edit or delete

If the mistake is minor, like a typo, edit the message. If you sent it to the wrong chat or by accident, delete it. Either way, the recipient doesn't have to read around the mistake.

## Wrong or outdated information - Strike it through

If the message contains information that is wrong or no longer relevant, and someone may have already read it, don't silently replace or delete it. Strike through the original text and add the correction next to it.

Readers who saw the original message might have already acted on it. If the text just changes, they have to compare it against their memory to work out what is different, and later replies in the thread may no longer make sense. A strikethrough shows exactly what changed and keeps the conversation readable.

<boxEmbed
  style="greybox"
  body={<>
    The client demo is on Thursday at 3pm *(edited)*
  </>}
  figurePrefix="bad"
  figure='Bad example - The time changed silently, so anyone who read "2pm" might not notice'
/>

<boxEmbed
  style="greybox"
  body={<>
    The client demo is on Thursday at ~~2pm~~ 3pm - the client asked to move it
  </>}
  figurePrefix="good"
  figure="Good example - The old time is struck through and the reason for the change is clear"
/>

The same applies when a whole message is no longer relevant, such as a question you have since answered yourself. Strike through the message and add a short note, like "Found it in the wiki", so nobody spends time replying.

In Microsoft Teams, use the formatting options or the Markdown shortcut. See [Use Markdown formatting in Teams](https://support.microsoft.com/en-us/office/use-markdown-formatting-in-teams-4d10bd65-55e2-4b2d-a1f3-2bebdcd2c772).

Editing a message doesn't notify anyone, so after a correction that changes the meaning, [let people know you updated the message](/inform-others-about-chat-message-updates).
