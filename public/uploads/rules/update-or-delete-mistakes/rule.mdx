Fix mistakes in chat messages you've sent. Edit or delete small slips, and strike through anything someone may have already read.

<endIntro />

## Typos and messages sent in error - Edit or delete

Edit a typo. If you sent a message to the wrong chat or by accident, delete it.

## Wrong or outdated information - Strike it through

If someone may have already read the wrong information, strike it through instead of overwriting or deleting it. Readers see what changed, and earlier replies still make sense. In Teams, use the formatting toolbar or [Markdown](https://support.microsoft.com/en-us/office/use-markdown-formatting-in-teams-4d10bd65-55e2-4b2d-a1f3-2bebdcd2c772).

If the whole message no longer applies, like a question you've since answered, strike it through and add a note such as "Found it in the wiki".

### Option A - Small changes: Correct it in the same message

Strike through the wrong text and add the correction next to it.

<imageEmbed alt="Microsoft Teams message marked Edited that reads: The client demo is on Thursday at 2pm (struck through) 3pm - the client asked to move it" size="large" showBorder={true} figurePrefix="good" figure="The sender struck through the old time and gave the reason for the change" src="/uploads/rules/update-or-delete-mistakes/teams-message-strikethrough-correction.png" />

Edits don't notify anyone. If the correction changes the meaning, [let people know you updated the message](/inform-others-about-chat-message-updates).

### Option B - Big changes: Post a v2 message

If most of the message changes, strike through the original and post the correction as a new message starting with "(v2 - reason)". The new message notifies everyone.
