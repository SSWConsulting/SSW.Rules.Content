If you notice a mistake in a message you sent in IM (e.g. Microsoft Teams), fix it. Edit or delete small slips, but strike through anything someone may already have read or acted on.

<endIntro />

## Typos and messages sent in error - Edit or delete

If the mistake is minor, like a typo, edit the message. If you sent it to the wrong chat or by accident, delete it. Either way, the recipient doesn't have to read around the mistake.

## Wrong or outdated information - Strike it through

If the message contains information that is wrong or no longer relevant, and someone may have already read it, strike through the original and add the correction. Don't delete it.

Readers who saw the original message might have already acted on it. If you overwrite the text, they have to compare it against their memory to work out what is different, and replies to the original may no longer make sense. With a strikethrough, they see the old and new text side by side and can follow the thread.

The same applies when a whole message is no longer relevant, such as a question you have since answered yourself. Strike through the message and add a short note, like "Found it in the wiki", so people don't spend time replying.

In Microsoft Teams, use the formatting options or the Markdown shortcut. See [Use Markdown formatting in Teams](https://support.microsoft.com/en-us/office/use-markdown-formatting-in-teams-4d10bd65-55e2-4b2d-a1f3-2bebdcd2c772).

Choose a method based on the size of the change.

### Option A - Small changes: Correct it in the same message

For a small change, like a time or a name, strike through the wrong text and add the correction next to it in the same message.

<imageEmbed alt="Microsoft Teams message marked Edited that reads: The client demo is on Thursday at 3pm - the client asked to move it" size="large" showBorder={true} figurePrefix="ok" figure="The sender corrected the time, but those who read &#x22;2pm&#x22; can miss the change" src="/uploads/rules/update-or-delete-mistakes/teams-message-overwritten-correction.png" />

<imageEmbed alt="Microsoft Teams message marked Edited that reads: The client demo is on Thursday at 2pm (struck through) 3pm - the client asked to move it" size="large" showBorder={true} figurePrefix="good" figure="The sender struck through the old time and gave the reason for the change" src="/uploads/rules/update-or-delete-mistakes/teams-message-strikethrough-correction.png" />

Editing a message doesn't notify anyone, so after a correction that changes the meaning, [let people know you updated the message](/inform-others-about-chat-message-updates).

### Option B - Bigger changes: Post a v2 message

If much of the message needs to change, a correction inside it becomes hard to read. Strike through the whole original message, then post the corrected version as a new message that starts with "(v2 - reason)". Posting a new message also notifies everyone.
