Your company has Microsoft 365 Copilot licences, and half the team tried it once. They typed "help me with this email", got a bland answer, and went back to doing it by hand.

Copilot works when you test it on real work, with prompts that say what you want and where to look. Run the prompts below in the apps you use every day, and you'll know in 10 minutes whether it saves you time.

<endIntro />

## Why should you test Microsoft 365 Copilot on real work?

Copilot can see your emails, meetings, chats and files (only what you already have access to). A generic prompt ignores all of that.

* &#x20;**Catch up fast** - Summarise the meeting you missed instead of scrubbing through the recording
* **Find the lost document** - Locate the file someone shared in a chat three weeks ago
* Skip the blank page - Get a first draft to edit instead of starting from nothing

## What prompts can you use to test it?

A good prompt has 4 parts: a **goal**, some **context**, a **source** and your **expectations**. The goal is required, and the rest make the answer better. See [Microsoft's guide to Copilot prompts](https://support.microsoft.com/en-us/topic/learn-about-copilot-prompts-f6c3b467-f07c-4db1-ae54-ffac96184dd5) for the full framework.

### Teams

```
Summarise the meeting I missed yesterday. List the decisions and action items, with an owner for each.
```

### Outlook

```
Create a table of tasks I need to complete from my emails over the past week. Include who asked and the due date. Keep it concise.
```

### Word

```
Draft a one-page project update for {{ CLIENT_NAME }} based on {{ FILE_NAME }}. Use a friendly, professional tone with 3 headings.
```

### Excel

```
Analyse this table and tell me the 3 biggest trends in plain English. Show a chart for the biggest one.
```

### Copilot Chat

```
What did {{ PERSON_NAME }} and I last agree on for {{ PROJECT_NAME }}? Check my emails and Teams chats from the last month.
```

## What else can you test beyond the Office apps?

Once the basics work, try the features that go further than chat.

### Researcher agent

Use it for the report you'd normally spend an afternoon on. It works through several steps across the web and your work data.

```
Research how {{ TOPIC }} is handled in our emails, Teams chats and SharePoint files from the last 3 months. Give me a one-page report with sources.
```

### Copilot Notebooks

Pin files, meeting notes and links in one place, then prompt across all of them. This tests whether Copilot sticks to your content.

```
Using only the items in this notebook, summarise the open risks for {{ PROJECT_NAME }} and list who owns each one.
```

### Copilot Search

Use it for a document you know exists but can't find. You get an answer plus the source file.

```
Find the proposal Sam sent about {{ CLIENT_NAME }} last quarter. Show me the file and who it was shared with.
```

## How do you check Copilot's answer?

* **Open the citations** - Click the reference links and confirm the source says what Copilot claims
* **Spot check the numbers** - Copilot can misread a table, so recalculate one or two totals
* **Follow up instead of starting again** - Reply with "make it shorter" or "use only the Teams chat"
