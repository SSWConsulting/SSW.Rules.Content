An AWS organization is easy to start and hard to restructure. The account layout, root user protection and audit log destination are decided in the first week, usually by whoever needed a sandbox that day.

These rules cover that first week and what follows, including Infrastructure as Code, identity, exposed credentials, Bedrock data residency and cost. Many assume a company that runs Microsoft Entra ID and Azure and is adding AWS alongside, and one rule maps each Azure service to its AWS equivalent.
